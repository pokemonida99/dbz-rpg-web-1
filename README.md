# 龍珠Z RPG 重製版（試玩：Z1 拉蒂茲篇）

為手機直向重新設計的版本：新的 JavaScript 引擎，沿用原版（RPG Maker VX 同人作品「ドラゴンボールZ RPG」）的素材與數值資料。
原版完整移植的「經典版」在另一個 repo：pokemonida99/dbz-rpg-web（橫向／原腳本執行）。

線上：https://pokemonida99.github.io/dbz-rpg-web-1/

> **換電腦／新的 Claude 接手：先讀 [`docs/HANDOFF.md`](docs/HANDOFF.md)**（設定步驟、使用者的規則、目前進度、下一步、開發流程）。

## 玩法改動
- **地圖**：不再用卡片移動，手指拖曳自由飛行；走一段距離隨機遇敵（原版機率約每 20 格一次），敵人組合照原版拉蒂茲區（甜菜人／球根人／奧尼恩／帕普金，1～3 隻）。
- **劇情與對話**：台詞直接從原版事件轉出來（簡轉繁），不刪減；對話框會顯示說話者的頭像（原版的 64×64 頭像）。地圖上的建築位置和原版相同（`145_Event_Check.rb`）。
- **戰鬥**：保留原版卡牌規則（手牌 6 張、攻／防星數、流派一致才能出必殺技、行動順序看攻＋防、傷害與迴避公式），介面改成直向大卡。
- **第二章（蛇道・桑修篇）**：打倒拉蒂茲後接原版劇情（天神、閻王、卡里克復活、卡林塔）；照原版讓玩家把比克／悟飯／克林／雅木茶／天津飯／餃子兩兩分到北・東・西；悟空獨自沿著蛇道走到界王星（Map005，只能走在原版第 2 層的道路圖塊上，轉彎處會自動順著路走，按住同一方向就能走完整條路；遇敵同拉蒂茲區）；接著北方小隊在桑修區（Map008，賈斯敏／哈布／西納蒙等 1～3 隻）打倒桑修，以悟空開始巴布魯斯修行收尾。東・西兩隊（尼奇、吉加）與界王修行小遊戲留給之後的章節。
- **第三章（界王星・尼奇篇）**：桑修之後照原版接悟空的第一次修行：界王星（Map009，只能沿著環狀的格子走、沒有遇敵）的修行格開始「抓巴布魯斯」（照原版移植 `Scene_Db_Bubbles_Training`：出攻擊星數不小於巴布魯斯的牌，1 勝 7、2 勝 8，累積 6 勝抓到；牌用完就中斷，勝場會保留；抓到後悟空得到 1000 經驗值、所有必殺技使用回數 +10）；接著東方小隊在尼奇區（Map010，遇敵同桑修區；烏龍送仙豆卡）打倒尼奇（與賈斯敏、西納蒙一起），以古雷格利修行的預告收尾。古雷格利修行與西方小隊（吉加區）留給下一章。
- **第四章（古雷格利修行・吉加篇）**：尼奇之後照原版接悟空的第二次修行：界王星（Map011，同樣只能沿著格子走、沒有遇敵）的五個修行格開始「用錘子打古雷格利」（照原版移植 `Scene_Db_Gregory_Training`：出攻擊星數不大於古雷格利的牌，他出 1 時 7、出 2 時 8 也算贏，累積 6 勝打中；牌用完就中斷，勝場會保留；打中後悟空得到 1800 經驗值、所有必殺技使用回數 +15）；接著西方小隊在吉加區（Map012，遇敵同桑修區；牛魔王送卡片）打倒吉加（與哈布、西納蒙一起），最後六個人在卡里克城會合（劇情變數 41 = 117）。之後的卡里克區由 `game.startChapter5` 接上。

- **第二部 第四章（基紐特戰隊）・第五章（弗利薩，Z2 結局）**：照原版 Map007 事件 2「イベント実行Z2」頁 445～561：那美克星 3 的池塘（第二部前半的地圖 26，前半播完頁 445 後由 `game.startZ2b` 接上；`game.startZ2Ginyu` 從頁 445 開始）→ 弗利薩的宇宙船、基紐特戰隊登場（原版地圖 27 的圖片演出）→ 悟空抵達、加入 → 基紐特戰隊戰（5 隻，剩最後一隻時多攻擊一次）→ 醫療室、龍珠沒反應、內魯、丹迪 → 那美克星 4（地圖 29，遇敵照原版 3～5 隻、比克一人時 1～2 隻、最終型態時換成強的一組）：西北的島召喚波侖加（地圖 28 的圖片演出）→ 比克復活、大長老去世 → 弗利薩（第一型態）→ 比克一個人去找內魯（同化的圖片演出）→ 弗利薩第二型態（變身演出 CE41）→ 第三型態（CE42，丹迪、悟空治好歸隊）→ 最終型態：悟空以外的同伴第一次倒下時戰鬥中斷，悟空變成**超級賽亞人**，弗利薩保留剩下的 HP 繼續戰鬥；打倒後超級貝吉塔來挑戰（貝吉塔離隊）。沒有人倒下就打倒最終型態時照原版走另一條路：超級元氣彈（CE147 的演出）→ 弗利薩還活著、克林、悟空變身 → 全力弗利薩。兩條路最後都是原版的 Z2 結尾旁白與「Z2 完」（變數 40 = 2、41 = 1100，Z3 待續）。地圖上還有那美克星人（技能說明、送卡）、年輕的那美克星人、宇宙船的戰鬥服（悟飯和克林換上原版的戰鬥服圖）、旅館、卡片、修行格。劇情戰鬥前自動存檔，輸了或讀檔會從那場戰鬥重新開始。開發用：`?dev=z2ginyu`（第四章開頭，頁 445）、`?dev=z2frieza`（比克同化後，弗利薩第二型態前）、`?dev=z2last`（最終型態前，悟空已歸隊）、`?dev=z2turles`（最終型態前、在達列斯・史拉格的地點旁），可加 `&timer`。**達列斯・史拉格支線**（照原版頁 514 → 地圖 30 → 頁 508 → 戰鬥 511）：概況 36（弗利薩最終型態之前）地圖 29 的 (11,5)，達列斯和史拉格登場（原版圖片演出），巴達克趕到加入隊伍（技能 能量波・大能量波・爆發波・復仇標槍・靈魂加農，CE227 的使用次數），打倒兩人後巴達克一直留在隊伍：對弗利薩、悟空變身、超級貝吉塔時有他的台詞，最終型態戰的額外攻擊照原版變多，Z2 結尾有他的告別（頁 512）。原版的「只有一個人的最終決戰」（巴達克篇，頁 3000～）與外傳的巴達克一味篇只能從時之間進入，本版還沒有時之間，所以沒有做。
- **超級賽亞人**（`src/supersaiyan.js`，之後的篇章也能用）：照原版 `on_off_super_saiyazin`，把角色換成超級賽亞人的另一個角色（悟空 3⇄14、悟飯 5⇄18、貝吉塔 12⇄19、特南克斯 17⇄20、未來悟飯 25⇄26、巴達克 16⇄32），經驗值（等級）、HP／KI、技能都帶過去（固有技能「賽亞人之血」變「賽亞人魂」），比原形態低的能力值照原版補成原形態的值；class 9（超）的人攻擊 ×1.3、受到的傷害 ×0.85（`docs/battle-rules.md` §4.1／§4.3）。戰鬥中可用「超賽變身」（技能 29，KI 100）變身，戰鬥後維持變身。`syncSuperSaiyan` 對應原版 CE155／CE157（時之間與本篇之間的同步）。Z2 的卡片流派照原版 `create_card_i`（沒有神・基・悟，悟空變身後沒有界，超級賽亞人戰起多了「超」）。
- **觸控出招**：原版的「戰鬥 → 手動」改成直接點卡片：點卡＝目前發亮的角色用這張卡；必殺技視窗外面點一下、或選敵人時點敵人以外的地方（或同一張卡）就取消這張卡。選好的卡片會掛上角色的小頭像，點那張卡或那個人的頭像只重選他一個人，「返回」從最後一個開始一個一個取消。全員選完出現大大的「出招！」再開始（設定「選完直接出招」打開就和原版一樣直接開始）。鍵盤：Enter／Z 確定、X／Esc 返回、1～6 選卡。
- **隊伍與作戰**：戰鬥時下排是「自動／菜單／逃跑」（Boss 戰沒有逃跑）；菜單裡可以看隊伍能力、換順序、設定每個人的作戰（優先攻擊的敵人、技能的選擇、KI 的消費），「自動」照作戰出招。地圖選單也有隊伍和作戰。原版 Z1 不能換上待命的成員（只有 Z3 時之間才有），所以沒有做。
- **特殊卡片**：照原版移植。打倒敵人會掉卡、劇情人物會送卡，Z 標記照原版隨機是卡片商店（用 CAP 買賣）、連線抽獎或神經衰弱，地圖選單有卡林大人的「合成」；地圖選單「卡片」和戰鬥中的「卡牌」可以使用（回復、改手牌、攻防提升、先攻、迴避、讓敵人停一回合、探測器等）。每張卡依 S/A/B/C 等級有持有上限。
- **成長**：照原版加入技能（固有技能隨等級取得；追加技能從隊友學會的技能中設置，戰鬥得到的 SP 學會，也可以用 CAP 設置／學會；悟飯(C) 卡開技能槽，最多 3 個）、ZP（每場戰鬥依敵人數、新的最高等級 +50；龜屋卡每 150 ZP 提升一次能力）、共有經驗值（每場戰鬥的經驗值都存進去，哥美拉卡分給角色）、必殺技熟練度（使用次數讓威力最多變兩倍）。被打倒的角色要等 HP 回滿（或住旅館）才會復活。隊伍畫面「看技能」可以看與設定技能。技能相關卡片：兔老大（不是一就是八）、那木／悟飯(B) 等技能卡（技能加入技能一覽）、加重衣（之後 5 場 SP ×1.5）、超聖水（ZP +15）、假面男（設定自由技能槽）、妖怪（讓 HP 1 以上的倒下角色復活）。
- **地圖上的系統**（照原版移植）：修行格（地圖 1 十格、蛇道三格、桑修區四格，速度修行小遊戲：出和修行卡星數／流派相同的牌，次數越多經驗越多）；帕普金（47,11）、布洛可（50,5）的事件戰；地圖選單的「概況」（前情提要，讀檔時也會播，可在設定關掉）、「情報」（占卜婆婆：戰鬥記錄、敵人情報）、「設定」（戰鬥 BGM、遇敵頻率、遇敵音樂、戰鬥速度、訊息高速化、跳過 OP／概況）、「地圖」（拖曳查看整張地圖）；一般戰鬥勝利後自動存檔（標題畫面「自動存檔」）；龍珠雷達（布爾瑪給的卡片 1，`openRadar`）。
- **經驗值**：用原版的「經驗值倍率」選項設為 8 倍，否則要打約 100 場才能挑戰拉蒂茲（約 Lv6-7）。
- 規則來源與公式整理在 `docs/battle-rules.md`。

資料重建（需要原版遊戲資料夾，例如 `../dbz-rpg-web-dist/game`）：
```bash
ln -s ../dbz-rpg-web-dist/game game          # 原版素材（不進 git）
ruby tools/extract.rb game/Data data $(ls game/Data | sed -n 's/^Map0*\([0-9]*\)\.rvdata$/\1/p')   # 全部地圖 .rvdata → JSON（系統 Ruby 2.6 即可）
python3 tools/build_data.py                  # → data/world.json（台詞在這裡轉繁體）
python3 tools/build_combo.py                 # → data/combos.json（組合技）
python3 tools/copy_assets.py game            # 只複製用到的素材到 assets/
```

## 本版自製素材
`assets/bg/battle_{night,dusk,day}.png`：直向戰鬥背景（400×600），用 ChatGPT 照原版 Z1 戰場地面的風格生成，再縮成像素、減色。每場戰鬥隨機選一張，同一場不會換。

## 發佈

每次推上去之前先跑 `python3 tools/bump.py`，會更新版本號並讓手機自動抓到新版。
