## 和其他檔案的關係

- 背景條、cut-in、pattern 32 用 `src/anime_goku_gohan.js` 的 stage（`agStage`／`agFrame`／`agCut`／`agEnd`）；那個檔只加了一行 `export function agFilms(pictures, launch)`，讓別的檔把自己的影片登記到它的 `launch`。沒有另寫背景條／cut-in。
- 傷害 41（爆発系 ZD 中，effect 102）anga 的檔沒有，寫在本檔 `andaEnd`；42 用 anga 的 `agZd`，22／23 用 `src/anime.js`。
- `src/combo-anime.js` 的 `BORROW` 拿掉 198／208（組合技 792、793～798、815、838 等現在播自己的片）。
- 組合技串接（`chain`）在兩位成員之間會清掉繪圖層，anga 的 `agStage()` 是快取的不會重掛；本檔用 `andaStage()` 在需要時重掛（anga 自己的片在組合技裡第 2 位以後也有同樣問題，未處理）。
- `src/z4b.js` 的 191～215、`src/zg_b.js` 的 194 舊借用沒刪（本檔較晚載入會蓋過去；怕和別的分工衝突，合併時可順手刪）。敵人方（`!this.p`）仍播那些舊借用片。

## 和原版不同

- 216 全功率地獄閃光：原版沒有片，只播衝擊波系傷害，兩人站在起始位置（x −70／602）；手機畫面裁切後兩人都在畫面外，只看得到地面與傷害數字。照原版保留。另外原版沒有任何事件或升級會學到 216。
- 原版在第 2294 等片自己 blt 的圖都畫在角色後面、effect_pattern 畫在角色前面，照做；粒子（超元気玉(元気) 的小點）用原版的 1/7 機率亂數，每次播放不同。
- 組合技裡（ComboDuel）照 anga 的規則不畫背景條與 cut-in。
- 手機寬度只顯示 640 舞台中間的一段（和其他招式一樣），地獄閃光特寫左側、能量波動 18 號特寫兩側會被裁掉一點。
