# 招式動畫 E 組 aen4：時之間「強」系列與 ZG 後段的敵人招式

檔案：`src/anime_foes_zg.js`（登記、影片、效果），共用舞台與共用 pattern 用 aen3 的 `src/anime_foes_common.js`（各 E 組原封不動複製同一份）。
跳關：`?dev=aen4`（吉加・尼奇・桑修(強)），`?dev=aen4<敵人編號以 _ 連接>`，例如 `aen4210_213_214`、`aen4215_216_238`、`aen4222_223`、`aen4253_254`。
主控台：`__aen4(技能, 我方第幾人, 敵人第幾個, 傷害)` 讓該敵人對該隊員出一次招（傷害 −1＝沒打中）。

## 原版規則
- 敵人必殺的攻擊 pattern＝技能編號 +10（all.rb 140149）；敵人出招時 `$btl_progress` 看敵人編號（54627），101 以後一律 Z3 分歧（59742），所以這些招全用 Z3_ 素材、Z3 背景條與 cut-in，和劇情變數 40 無關。
- 每招都是 31 → 32 → 招式片 → 傷害 pattern；全體招第 2 個目標起（@all_attack_count ≥ 2）跳過 31／32，背景條與 cut-in 沿用前一個目標結束時的狀態，再加 case 裡的設定。
- 巨大角色（元素 23：金屬古拉・核心、達列斯(大猿)、史拉格(巨大化)、奧佐特(變身)）出招時原版畫在 (x−48, y−48)，影片照這個位置畫。
