# 招式動畫 E 組：敵人招式（照原版逐格移植）

做法、檔案規則、測試要求和 A～D 組一樣，先讀 `docs/anim-ab-plan.md`、`docs/anim-cd-plan.md`（含開頭的完成說明）與已做好的 `src/anime_*.js` 當範本。重點：

- 讀原版 `research/all.rb` Scene_Db_Battle_Anime 該招的 pattern 逐格移植，用原版圖與音效，不重畫、不自創。我方 Z3 是技能編號 +2100；**敵人招式的 pattern 編號規則請先在原版查清楚**（敵人攻擊的分歧在 Duel 的敵人側），照原版依時期選圖、畫必殺技背景條與 cut-in。
- 很多敵人的「能量波／連續能量波／強力能量波／爆發波」是不同技能編號但原版可能共用同一個 pattern：照原版實際對應，共用的就共用，不要各寫一份。
- 影片寫在自己的新檔（下表），`addMoves` + `Object.assign(Duel.prototype, …)` 登記，`src/main.js` 加一行 import，`tools/copy_assets.py` 收自己的 `pic('…')` 與音效清單。背景條、cut-in、`launch` 包裝請 import 既有的（`src/anime_goku_gohan.js` 的 `agRegister`／`agFilms`、`src/anime_zfighters.js`），不要再寫新的一份；需要的 export 只加一行。
- 敵人在戰鬥中的變身（達列斯大猿、史拉格巨大化、賽魯等）沿用 `src/battle.js` 既有的 `FOE_FORMS`／`transform`，不另起一套。
- 從 `main` 開 worktree 分支，不要合併 main、不要 push。`game`／`research` 連結主資料夾，缺的 `data/*.json` 從主資料夾複製。
- 測試：390×844 與 375×667、`&timer`、主控台無錯誤、圖檔都載入；每招在戰鬥中讓敵人實際用一次（可在主控台指定敵人出招），截圖幾格對照原版。跳關用自己的前綴。
- **每做完一個敵人（或一組）就用一句中文回報**。完成後提交，回報分支名、每招做到什麼程度、和原版不同的地方、測試結果。
