# 招式動畫 F 組 cmb：Z2 以後的組合技片（2026-11-03）

`src/combo_z2.js`：照原版 Scene_Db_Battle_Anime 的 18xx／19xx（與 2839）逐格移植，共 22 個組合技。

## 做法

- **時期分歧照原版**：組合技的攻擊 pattern 是「編號 + 10」，`$btl_progress`（變數 40）= 1 走 Z2 區塊（all.rb 56692）、≥ 2 走 Z3 區塊
  （59742）。兩個區塊大多派發同一個 18xx 片，只差 `@tec_back_small` 和少數傷害；不同的是 739（Z2 1839／Z3 2839）、722（傷害
  Z2 23／Z3 41）、748（Z3 區塊沒有 `@tec_back_small`）。Z1 篇八招（701 706 708 739 748 751 752 819）在變數 40 = 0 時照舊播
  `src/combo-anime.js` 的 Z1 片，≥ 1 時播這裡的片。
- **舞台 `Cz`**：保留原版實例變數（@battle_anime_frame、@effect_anime_pattern／frame／type、@ray_anime_*、@back_anime_*、@ax @ay
  @gx @gy（@gx 每格反號，output_battle_anime）、@output_anime_type、@btl_ani_cha_chg_no、@scombo_cha1～4 與 anime_type、
  @btl_ani_tokusyu_flag、@ray_color、@damage_huttobi／@damage_center、@tec_kyouda_se），每個片是原版 case 一格一格寫成的
  `pNNNN(z, f)`；pattern 直接 blt 的畫在角色後面，effect_pattern 畫在前面，順序和原版每格相同（output_back → pattern → 角色 →
  effect → cut-in）。frame 0 照 anime_pattern 開頭歸零 @ax 等，`@battle_anime_frame = -1／0` 的重來也照做。
- **背景條與 cut-in**：沒有另寫，用 `src/anime_goku_gohan.js` 的 agStage（`d.agStage()` 後設 `st.era`；pattern 32 第 30 格起
  `tecFrom／cutFrom`）。ComboDuel 的 cut-in 是發動者（`b.duel.m`，原版 `$partyc[@chanum]`），set_chr_display_out 後換敵人的。
  `@tec_output_back`、`@tec_output_back_no`（1：兩側）、`@chr_cutin = false` 都接到 agStage。
- **傷害**：41／42／44（爆発系 ZD中／大、Z2特大）、22 與 78（衝撃波系、縦；`@tec_kyouda_se` 時 ZG 打撃4）在 Cz.damage 裡照原版
  跑（背景條、cut-in 保留）；23／27 用 src/anime.js 既有的 explode／blownUpLeft。
- 同族寫成一份：1851／1857（比克／青年，只差角色與一列姿勢）、1852／1858（同）、1839／2839（2839 = 1839 加長集氣，之後晚 160 格）、
  748 的整串（1848 → 狼牙風風拳 171 → 1848 → 龜派氣功 1105，派發器每格的判斷也照做）。
- 圖：95 張 `pic('…')`（Z2_／Z3_ 依時期），音效 `CMB_SOUNDS` 35 個；缺的已複製到 `assets/`，`tools/copy_assets.py` 加了掃描。
  組合技自己的圖（含背景條、cut-in 圖）push 進 `ANIME_IMAGES`，戰鬥開始就預載。

## 和原版不同

- **手機畫面較窄**：713 兩人在 x 66／470 對峙，手機上兩人與光束起點往中間收（`Cz.apart`，光束仍在中線相遇）；728 兩人後退只退到
  畫面可見的邊、對話框不出左邊界，衝刺終點不變。其他照原版位置（有些角色在左右邊緣會被裁一點，和既有片一樣）。
- 對話框文字（728、805）原版用自己的字型點陣圖（output_mozi），這裡用重製版的 Cubic11 字型、黑字，原文簡體改繁體。
- 2839 的效果 375／392 原版 effect_pattern 裡沒有，不畫但計數照跑（和原版相同的結果）。
- 1904 原版「沒命中就跳到 530 格」的分支不用（組合技一定命中）。
