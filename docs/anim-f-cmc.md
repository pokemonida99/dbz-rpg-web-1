# 招式動畫 F 組 cmc：28xx 組合技片（43 個，2026-11-03）

照原版 `research/all.rb` Scene_Db_Battle_Anime 的 anime_pattern 28xx 逐格移植（組合技編號 +10 = 攻擊 pattern → 31 → 32 → 28xx 片 → 傷害 pattern），
連同用到的 effect_pattern／back_anime_pattern 子 pattern、原版圖與音效。這 43 個組合技都要變數 40 ≥ 2（`data/combos.json` era 2），原版只在
`$btl_progress` 2 的派發區（all.rb 61560 起）有它們，所以都只有這一個時期的片，一律用 Z3_ 的圖。

## 和原版不同

- 原版 718、719、729、746／749、780 等組合技打全體時，第二個目標起播較短的片（`@all_attack_count >= 2`）；重製版組合技只打一個目標，所以只做第一個目標的片。
- 原版的 bug 照做：718 由 18 號發動時，飛進來的是 18 號和 16 號（18 號出現兩次）；723 火箭拳在 451 格之後原版移回左邊但計數沒歸零，所以已經在畫面外。
- 背景動畫、效果的計數器照原版（@back_anime_frame／@effect_anime_frame／@ray_anime_frame，換 pattern 時不自動歸零）；@scombo_chaN_anime_type 原版會沿用上一次組合技的值，重製版每次從 0 開始。
- cut-in 用 `ZfStage` 的寫法（Z3_味方カットイン，列 = 角色編號 − 3），沒有照 set_battle_cutin_name 的服裝差分（亀仙人便服、特蘭克斯戰鬥服等）。
- 手機畫面左右會被裁：這批片沒有特別往中間收（人物多半在中央），少數從畫面左右外側進場的鏡頭在窄螢幕上進場會晚一點看到。
