# 招式動畫 F 組：組合技專屬演出（照原版逐格移植）

清單來自 `docs/combos.md`「留給招式動畫大工程的清單」：目前用 chain（參加者依序放自己的招式）的 152 個組合技，加上 Z1 篇 8 個組合技在
Z2 以後的版本（原版 `$btl_progress` ≥ 1 改播 18xx／19xx／28xx 的另一組片）。原版沒有派發 pattern 的 5 個（816、817、826、838、878，
清單裡寫「—」）原版就拿不到，不用做。

做法、檔案規則、測試要求和 A～E 組一樣，先讀 `docs/combos.md`、`docs/anim-ab-plan.md`、`docs/anim-cd-plan.md`，以及
`src/combo-anime.js`（已照原版做好的 20 個組合技片，`ComboDuel`、`crew`／`lead`／`sheet()`／`who()`）當範本。重點：

- 讀原版 `research/all.rb` Scene_Db_Battle_Anime 該組合技的 anime_pattern 逐格移植，用原版圖與音效，不重畫、不自創。組合技的攻擊 pattern 是
  「組合技編號 +10」再依時期分歧：Z1 是 8xx（+100）、Z2 是 18xx（+1100）、Z3 以後是 28xx／29xx（+2100）。**同一個組合技在不同時期可能有不同的片，
  照原版的分歧做**；清單括號裡是原版主要派發的那個 pattern，請在原版確認還有沒有別的時期版本。
- 同一族（OS 射擊、FOS 射擊、雙重爆裂、賽亞攻擊、「欠你人情」系列…）原版若是同一段程式換角色／換位置，就寫成一份帶參數的片，不要各抄一份。
- 影片寫在自己的新檔（下表），用 `addComboFilms({ 組合技編號: ['影片名', 傷害] })` 登記（`src/combo-anime.js`；傷害可以是原版的 damage pattern
  編號 23／22／27／28／43，或自己寫的方法名字串），`Object.assign(ComboDuel.prototype, { *影片名() {…} })` 加方法；`src/main.js` 加一行 import；
  `tools/copy_assets.py` 收自己的 `pic('…')` 與音效清單；組合技自己的圖 push 進 `ANIME_IMAGES`（照 `combo-anime.js` 最後兩行）。
- 必殺技背景條、cut-in（Z2 以後原版會畫角色 cut-in）、`launch` 包裝：import 既有的（`src/anime_goku_gohan.js` 的 `agStage`／`agFilms`、
  `src/anime_zfighters.js`、`src/anime_foes_common.js`），需要的 export 只加一行，**不要再寫一份新的**。
- 不改別組的檔，只改自己的新檔、`src/main.js` 一行 import、`tools/copy_assets.py` 自己的幾行；`src/combo-anime.js` 只在需要時加一行 export。
- 從 `main` 開 worktree 分支，不要合併 main、不要 push。`game`／`research` 連結主資料夾，缺的 `data/*.json` 從主資料夾複製。
- 測試：390×844 與 375×667、`&timer`、主控台無錯誤、圖檔都載入；每個組合技用 `?dev=cmbxz2／cmbxz3／cmbxz4／cmbxzg`（`src/combo_dev.js`）＋主控台
  `__cmbx(組合技編號)` 實際發動一次，截圖幾格對照原版流程；隊伍湊不出的組合技可以直接建 `ComboDuel` 播。跳關若要新增，用自己的前綴。
- **每做完一族（或幾個組合技）就用一句中文回報**。完成後提交，回報分支名、每個組合技做到什麼程度、和原版不同的地方、測試結果。
  做完的組合技請從 `docs/combos.md` 的 chain 清單移到自己的文件（`docs/anim-f-<前綴>.md`），不要改 combos.md 以外別人的段落。
