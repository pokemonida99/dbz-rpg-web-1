## 原版規則

- 敵人出招的 `$btl_progress` 看**敵人編號**（all.rb 54627，`$ene_str_no = [1,31,101]`）：1～30 Z1、31～100 Z2、101 以上 Z3。本組的敵人 142～182 全部走 Z3 分歧（59742），圖用 `Z3_`。
- 攻擊 pattern＝技能編號＋10（140149），case 裡先 31（從上方飛入）→ 32（必殺技！）→ 招式片 → 傷害 pattern。
- 敵人側（`@attackcourse == 1`）：`output_battle_anime` 每格先 `@ax = -@ax` 再 `@enex += @ax`，我方 `@chax += @gx`（不反號）；必殺技橫條往右捲；cut-in 先畫敵人的 `Z3_敵カットイン`（列＝敵編號−101），`set_chr_display_out` 之後換我方的。

## 和原版不同的地方

- 開關 463（依傷害大小換爆炸）沒做，和 A～D 組一樣用各傷害 pattern 的預設爆炸。
- 手機寬度裁掉舞台左右兩側（重製版共通），左右直條在 390／375 寬只看得到一部分。
- 原版裡幾處程式本身的怪地方照搬：沒有重設的 `@ax` 會讓敵人每格左右抖、2636 計數器跨段不歸零、2637 第 157 格起岩石高度跳回、2694 等排在範圍外永遠不會執行的分支。
- 2618 合體超能力、2707 雙重攻擊畫另外兩人時用重製版的中文檔名（`Z3_戦闘_敵_赞佳.png` 等，和原版日文檔名的圖完全相同）。
- 535 便便攻擊的傷害 25 照原版換成 DB3 SE061 並顯示傷害數字（`@ene_set_action 545` 的特例），寫在片裡。
- 影片最後一格（原版 `anime_pattern_fromat` 那格）不另外顯示，每片比原版少 1 格。
- 只有敵人編號 ≥101（Z3 分歧）才播這些片；同技能的其他使用者照舊播原本的片（`feRegister` 記住登記前的片）。
