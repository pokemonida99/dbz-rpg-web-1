# 卡片效果 A（cards-a）

分工見 `docs/cards-plan.md`。程式 `src/cards_a.js`，資料 `tools/build_cards_a.py`（`world.cardsA`、技能資料、素材清單）。
原版出處都是 `research/all.rb` 的行號。

## 需要的共用檔掛鉤

戰鬥、組合技、大地圖的效果靠三個掛鉤物件：`src/battle.js` 的 `battleHooks`、`src/combo.js` 的 `comboHooks`、`src/field.js` 的
`fieldHooks`（main commit 8941408，本分支以 cherry-pick 取得）。
`src/cards_a.js` 用 `import * as` 讀這三個物件：**還沒有掛鉤時遊戲照常運作**，卡片也能用（技能會加進清單），只是戰鬥／飛行效果不會觸發。

| 掛鉤 | 用途 |
|---|---|
| battleHooks.cardFor | 鐵壁；大猿時「必」卡算流派 |
| battleHooks.kiCost | 手下留情 |
| battleHooks.power / dealt / taken | 大猿：必殺技威力 ×2、造成 ×1.5、受到 ×0.7 |
| battleHooks.act | 悟飯的「大猿變身」 |
| battleHooks.hit | 惡作劇（防禦／攻擊／變更） |
| battleHooks.hurt | 硬撐、高昂的鬥志、敵人切尾巴 |
| battleHooks.recover | 保持實力、精神統一、大猿回復增加 |
| battleHooks.end | 戰鬥結束時大猿變回（作戰「變身狀態」是不保持時，預設） |
| play() 的 `size: m.spriteSize` | 大猿的 192×192 戰鬥圖 |
| comboHooks.less / blocked | 阿吽的呼吸；大猿不能組合技 |
| fieldHooks.step | 飛機 |

### 55 月亮和尾巴（run_card 46065）
只有悟飯、而且開關 70 沒開時能用（其他人：錯誤音，不消耗）。Z1（變數 40＝0）學會「大猿變身」(skill 51，KI 100)，Z2 以後學會「爆裂衝擊」(52)。開關 70 打開。
戰鬥中也能用（會開選人畫面）。

**大猿變身**（Z1，on_off_oozaru 13109）：戰鬥中使用不造成傷害，悟飯變成大猿——
暫時忘記魔閃光與大猿變身、戰鬥圖換成原版 `Z1_戦闘_ゴハン(大猿)96×96.png`（192×192）、必殺技威力 ×2（原版只對用過的招式加倍，照做）、
造成傷害 ×1.5、受到傷害 ×0.7、「必」卡算自己流派、回合回復 HP ×1.3／KI ×1.2、不能組合技、被敵人切尾巴的招式（屬性 25）打中就變回。

### 76 飛機（147041）
變數 420 ＋5（上限 999），之後每次「卡片移動」移動量 ×2 並扣 1（說明文字的「剩餘 N 回合」照變數顯示）。只能在地圖上用。
重製版是自由飛行：一次移動＝4 格（同巴布魯斯），效果中飛行速度 ×2，每飛完一次移動的時間扣 1；遇敵與巴布魯斯的計數仍照原本的步數
（原版是每次移動判定一次，移動量變兩倍不會多遇敵）。效果結束時提示「移動量加倍的效果結束了」（原版沒有提示，和巴布魯斯一樣是重製版加的）。
變數 420 和 cards-b 的 173 氣墊車（＋15）共用：加倍、遞減、結束提示都在這裡的 `fieldHooks.step` 統一處理，氣墊車只負責加 15。

### 79 老鼠（Scene_Db_Status 視窗 13，43585）
選一位用假面男在「自由」技能欄設定過技能的成員，確認「卸下技能：○○／要卸下這個技能嗎？／※卸下的技能無法恢復為原狀！」
（是的／取消），是的 → 那一欄回到「自由」、可以再用假面男設定。只能在地圖上用。

## 和原版不同

- ~~大猿戰鬥後就變回~~（第一批小修正 tac 已改成照原版）：戰鬥後的 `off_oozaru_all`（all.rb 13083）只在悟飯的作戰「變身狀態」
  `$cha_tactics[3][5] == 1`（不保持，**原版預設**：`set_cha_tactics_nil_to_zero` 14330）時變回；選「保持」就留到下一場。
  劇情的強制解除也接上了：Map007 各頁的 `#ゴハン大猿OFF`（桑修、尼奇、吉加、卡里克、貝吉塔戰後與威洛博士戰後，
  `tools/build_data.py` 轉成 `tacApeOff` 節點）、共通事件 160「大猿全解除」（進出時之間、時之間的隊伍變更：`apeOffAll`，`src/timeroom.js`）。
- ~~大猿變身沒有滿月演出、魔光砲沿用一般影片、頭像仍是悟飯~~（batch2 viz 已做）：滿月升起與臉變成大猿（anime 151，`src/anime.js` gohanApe）、
  大猿的魔光砲從嘴巴發射（anime 146 的大猿分支，apeMakouhou）、Z1 的戰鬥狀態頭像換成 `Z1_顔大猿`（`src/viz.js`）。
- 變回時：原版一律「學會魔閃光」，重製版只還原變身前已經會的；大猿變身照原版（Z1 用過卡片才會）。
- 惡作劇、高昂的鬥志、硬撐等「命中時」技能：原版組合技命中時參加者的技能也會發動，重製版的組合技目前不呼叫（和既有的金縛術一樣）。
  技能發動時的技能名框已做（batch2 viz，`src/viz.js`）。
- 保持實力和再生能力同時有時，原版是加總後一起進位，重製版分開進位（最多差 1 HP）；手下留情是在其他 KI 倍率取整後再 ×0.75（最多差 1 KI）。
