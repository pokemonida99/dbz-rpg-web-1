### 技能卡的技能（效果在 `src/cards_story.js`，掛在 `growth.skillHooks`）
- **422 顛倒**（get_battle_skill 6863）：出的卡攻防星數反轉（a → 7−a、g → 7−g），在ミラクル全開パワー之後。
- **393～401 輕視**（set_damage_add 14480／15850）：自己的卡攻＋防 > 敵人卡攻＋防 時，造成傷害 ×1.15～1.35、受到傷害 ×0.90～0.70。
  攻擊方原版只看技能有沒有放在欄位（`temp_cha_skill.index`），防禦方看有沒有學會（chk_skill_learn），照原版。
- **421 交換**（get_attack_hit_skill 17309）：攻擊命中、沒有先制（少年卡）時，自己這張卡和敵人的卡整張交換。
- **260 吸收（攻擊）**（17330）：攻擊命中時敵人卡攻 −1、自己卡攻 +1（0～7）。

## 需要主 session 改的共用檔
完整內容在筆記資料夾 `cst-hooks.md`，測過的 patch 是 `cst-hooks.patch`。
- `src/items.js`：匯出 `memberFx(m)`（波倫加的攻防 UP、交換看少年旗標）；tryUse 的提示順序（戰鬥專用的掛鉤卡在地圖上顯示「只能在戰鬥中使用」）。
- `src/growth.js`：`skillHooks = { pre, card, dealt, taken, hit }`；`src/battle.js`：把卡傳給 dealt／taken／onHit，`keepPlans` 的 cur 為 -1 時改 null。
- `tools/build_z4e.py`：`z4e2941` 加 `{item:[78,-99]}`、`z4e2801` 加 `{item:[78,1]}`。
沒加這些時本分工的程式不會出錯：波倫加只是沒有攻防 UP、四個技能學得到但沒效果；keepPlans 的問題在 cards_story.js 先暫時保護。

## 順手修的資料
`world.drops` 少了 18 個後來才加進 world.enemies 的敵人（拉蒂茲、吉加、尼奇、卡里克、基紐特戰隊、Z2 弗利薩各形態、超貝吉塔、達列斯、史拉格），
原版每個敵人都會掉卡（get_item_card），在 `tools/build_cards_story.py` 補上。

## 和原版不同
- 卡片使用畫面照重製版：沒有原版的卡片變化動畫（閃爍幾格），改成手牌閃一下。
- 筋斗雲的隊伍變更用重製版的 memberChange（多一個「取消」）。
- 卡片商店（openShop）判斷持有上限時不會把波倫加當 S 級（只有卡片畫面會）；原版只有 ZG 追加商品有波倫加。
