# 組合技（Sコンボ）全收錄（大工程第一批 cmb2，2026-11-02）

原版 172 個組合技（`data/scombo.json` 252 列）全部收進 `data/combos.json`（`tools/build_combo.py`），規則在 `src/combo.js`，
動畫在 `src/combo-anime.js`。規則本體見 `docs/battle-rules.md` §3.4／§4.2。

## 做了什麼

- **252 列全收、照原版順序**：同一個組合技可能有好幾列（基本形態與超級賽亞人是不同角色：悟空 3／超悟空 14、悟飯 5／18、
  貝吉塔 12／19、特蘭克斯 17／20、未來悟飯 25／26、巴達克 16／32），每列各自判定；學會與使用次數照組合技編號算。
- **開放條件**（`get_scombo_list` all.rb 8821、`chk_scombo_flag` 140311）：開關（`sw`）／變數（`v`，原版沒有列用到）、
  劇情進度（`era` ＝變數 40 下限：Z2 起 1、Z3 起 2；「一旦ボツ」的 859 是 3，永遠不開）。
  開關大多由已轉換的劇情頁打開（`world.json` 裡的 `{"sw": …}`，例如 Z2 結局頁 508 開 780／1111／1115、ZG 各篇開 1152～1192）；
  其餘照原版讀檔時跑的 **CE34「後から追加設定」的 Sコンボ段**與 **CE205「Sコンボ切り替えチェック」**（悟飯會激烈魔閃光 53 還是
  超龜派氣功 54、特蘭克斯 177／178 決定哪一列開），轉成條件節點 `catchUp`，每次判定與開一覽前跑一次（`catchUp(state)`）。
  另外補一條：Z2 開始時 Map007 事件 2 頁 3 開的 112（氣的開放），重製版的 Z2 開頭沒有播那頁，用「變數 40 ≥ 1」補上。
- **原版沒有任何地方打開開關的 11 個**（實際上拿不到）照原版保留但不開放：511 眠れる力 723、519 ダブル殘像拳(悟空＆克林) 746、
  769 ダブルませんこう 771、1118 熱戦・烈戦・超激戦 812、1122 どけ！オレが破壊する 816、1123 どけ！バカヤロー 817、
  1132 サンキューヤムチャ改 826、1147 戦場の女神 838、1171 弟子コンビアタック 862、1173 あっちいってけろ改 864、1191 魔・狼・鶴 878。
- **參加條件補齊**（照 140426-140480）：被定身（超能力）的不能參加；學了「局外人」(430、644～651) 或「旁若無人」(476～484) 的
  不能參加；**大猿列**（`oozaru_put` 1，只有 742 強襲サイヤ人：多瑪・莎莉巴・多達布・普普堅全員大猿）要全員是大猿，其他列全員都不能是大猿。
- **組合技一覽**照原版 `Scene_Db_Scombo_Menu`（144060）：有超賽欄的列，該超賽角色在隊伍裡才顯示超賽那列、不在才顯示基本那列；
  大猿列只在該角色是大猿時顯示；同一個組合技只列一次。
- **動畫**：沒有專屬演出的組合技用「參加者依序放自己的招式」（`chain`）。103 個參加者招式裡有 4 個還沒有動畫，借原招式的：
  超元氣彈 19 → 元氣彈 18、瞬間移動龜派氣功 27 → 超級龜派氣功 26、18／17 號的能量波動 198／208 → 193／203。
  **照原版逐格做了「雙重龜派氣功」一族**（786～790：悟空／悟飯／克林／雅木茶／未來悟飯＋龜仙人，anime 2886～2890）：
  發動者上升（龜仙人發動則下沉）、夥伴從旁飛進（effect 89／90）、上下排好（92）、兩人各一團集氣光環（back 201 ×2）、
  兩道大光束（effect 359～362，各版本位置不同）、最後敵方特大龜派氣功（48）＋大爆炸（damage 43）。用到的 3 張 Z3 圖已加進
  `tools/copy_assets.py`（掃 `combo-anime.js` 的 `pic('…')`）並複製到 `assets/`。
- 招式視窗的組合技提示（可發動／等隊友／條件不符／卡不符）、學會通知「恭喜！」、熟練度（組合技與各參加者招式各 +1）沿用既有系統，新組合技都適用。

## 和原版不同

- 原版第一輪判定只要求「發動者的招式在該列裡」，發動者本人不一定是參加者；重製版要求發動者是參加者（沿用上一批）。
- 原版玩家自訂組合技優先順序（變數 358、``、CE205 的 `tecchg_player_scombo_priority`）沒做，一律照資料順序。
- CE34 原版只在讀檔時跑，重製版每次判定前跑（條件都是看目前狀態，結果相同；例如 445 之後 512／1108／553 關掉換成新列）。
- 原版每個組合技都有專屬演出；重製版除了下面「已做」的 20 個，其他先用 chain（見下方清單）。
- 戰鬥訊息「A＋B 的組合技！」的人名照資料裡參加者順序，不是發動者在前（原版不顯示這行，是重製版加的）。
- 一些組合技名稱在原版漢化資料裡沒翻（例如「ノンステップバイオレンス」），照原版保留日文。
