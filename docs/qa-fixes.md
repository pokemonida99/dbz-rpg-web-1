# 通關測試修正（2026-11-04）

兩份通關測試報告（Sonnet、Opus，在 repo 外 `dbz-rpg/qa/qa-sonnet.md`、`qa-opus.md`）找到的問題，這一批修的：

| 問題 | 修法 |
|---|---|
| 悟空在 Z2 學會超元氣彈（招式 19）後，點悟空的牌畫面凍結 | `tools/build_data.py`：劇情頁教的招式一律收進 `world.skills`；19 的戰鬥片先借元氣彈的（`src/anime.js`）；招式視窗與隊伍畫面略過沒有資料的招式；`main.js` 的 `frame()` 包 try/catch，一次畫圖錯誤不再讓整個遊戲停住 |
| Z4 完之後「繼續遊戲」卡死（隊伍只剩比克、掉到第二章的頭目流程） | `src/z4f.js` `afterZ4`：結局時與讀到這種存檔時，把賽魯遊戲暫存的隊伍（`flags.z4fTmp`）還原、擂台標成打完；`onBoss` 對已打倒的頭目直接略過 |
| 缺圖：金吉鎮、飛機；缺 BGM：ZSSD 家2 等 5 首 | `tools/copy_assets.py` 加通用掃描：`src/*.js` 裡寫到、原版有的圖，`world.json` 裡用到、原版有的 BGM |
| Z4 完的標題畫面寫 ZG／時之間「本版尚未製作」 | 開放清單改成現況，副標「重製版・Z1～Z4・時之間・ZG」 |
| 6 人以上戰鬥，四位數 HP 數字互相重疊 | 窄欄位時數字縮小到放得下（`num` 的 `fit`） |
| 悟空 HP 1860／1700 超過上限 | 每回合開始把 HP／KI 夾回上限 |
| 譯名殘字：特蘭克斯ス、特蘭克斯く、賽亞人人、恐竜、惑星戦士、宇宙里、布利夫／布里夫、可能っ、帕布金 | `build_data.py` 的 `TEXT_FIXES`（只改劇情文字與說話者，不碰檔名） |
