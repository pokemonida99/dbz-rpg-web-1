## 3. 共用檔的改動

- `src/battle.js`（只用既有掛鉤之外的**兩行**，剛腕）：`onCard` 開招式視窗的條件加 `&& !growth.ext('normalOnly', false, this, m)`；`autoPlan` 選招式的條件同樣加這個。
- `src/items.js`：`import { ext } from './growth.js'`；`firstMovers` 問 `ext('sente')` 並照隊伍順序排；掉卡的 `rand(den)` → `rand(ext('drop', den, b, f, id))`。
- `src/main.js`：`import './skills_d.js'`（跳關前綴 `skc` 本來就在清單裡）。
- `tools/build_items.py`（BASE）、`tools/build_growth.py`（EXTRA）、`tools/build_cards_square.py`（BONUS 102／65）、`tools/build_data.py`（最後呼叫 `tools/build_skc.py`）。
- `src/combo.js`（cmb2 的檔案）：**沒有改**。局外人／旁若無人／剛腕「不能參加組合技」需要 combo.js 在挑參加者時問 `growth.ext('noCombo', false, b, m)`（true 就排除這個人，原版 `chk_scombo_flag` 的 `return 3`）；
  `src/skills_d.js` 已經登記好 `noCombo`，請合併時在 combo.js 的參加者檢查加這一行。剛腕本來就不會選招式，所以實際上只差局外人和旁若無人。同調用的是既有的 `ext('combo')`。

## 4. 和原版不同、或沒做的地方

- **組合技的排除**（局外人、旁若無人）：見上一節，要 combo.js 加一行才會生效。
- **光之旅的量表**（50164 的累計格數顯示）沒做，只有效果。
- **鋼鐵意志被定身時的技能名**（17967，只是顯示）沒做。
- **卡牌掉落**：原版分母 1 的掉落物在有這技能時會變成 `rand(0)`（浮點數），等於永遠不掉；本版維持 1（必掉）。
- **身心如一與拖延時間**的 HP／KI％ 本版和再生等技能分開進位（原版加總後一次進位），可能差 1。
- **韌性**的被打中次數：原版只算傷害不是 0 的命中，本版算所有命中（包含 0 傷害的定身招式）。
- **吸引**的遇敵頻率是換算的（見上表）。
- **被動技能在選卡時就改星數**：原版在選卡當下就改卡片（`get_battle_skill ..., 0`），本版和既有的ムダのない動き一樣在出招時才改（數值相同，只是選卡時看到的是改之前的卡）。
