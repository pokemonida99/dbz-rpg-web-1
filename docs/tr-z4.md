# 時之間 第 2 階段：Z4 的區域（`tr_z4`）

程式：`src/tr_z4.js`；資料：`tools/build_tr_z4.py`（由 `tools/build_timeroom.py` 呼叫，寫進地圖 87～95、`world.pois`／`world.areas` 的這幾張地圖、`world.trZ4`）。
共用工具（`registerArea`／`registerTrSpot`／`enterArea`／`leaveArea`／`trBattle`）見 `docs/timeroom-plan.md`，第 1 階段見 `docs/timeroom.md`。

## README 用的說明

> **時之間：Z4 的區域**：Z4 時之間大廳（Z4 通關後地圖 85、通關前 86）的七扇門：威洛（強）、賽魯第一形態、賽魯第二形態、金屬古拉、大格提斯塔（金屬古拉核心）、人造人間 13 號、賽魯遊戲（要 Z4 通關）。每區是主線地圖的複製（飛行），有卡片格、旅館、修行格、遇敵，頭目可以一直重打（不給經驗值，改給共有經驗值、CAP、SP，偶爾掉時之間特殊卡片，戰後全員回復）；13 號區打完 13 號會接著打合體 13 號，區內有往三個人造人間的捷徑格。「絕望的反抗」「另一個結局」是第 3 階段。
> 開發用跳關：`?dev=trz4`（Z4 通關後的時之間 Z4 大廳）、`trz4before`（通關前，地圖 86）、`trz4willow`／`trz4cell1`／`trz4cell2`／`trz4metal`／`trz4core`／`trz4android`／`trz4cellgame`（直接在該區頭目旁邊）。

## 地圖上的其他東西

- 卡片格、旅館（`z2inn`，原版頁 11 的變數 43 分支）、修行格：照 `Event_Check` 的座標，和主線一樣每次停留只能用一次。
- 地圖 95 (38,29)：**卡片特殊**（變數 44 = 40 再 `chk_card`），和主線 `src/z4f.js` 的做法一樣。
- 地圖 94 的六個捷徑格（9761～9766）：15 號旁 (11,23)↔13 號旁 (62,17)、15 號旁 (11,25)↔14 號旁 (31,21)、14 號旁 (34,21)↔13 號旁 (62,19)（各自兩頁）。原版是直接移動（沒有音效）。
- 頭目的站姿：地圖事件的圖（地圖 87 enemy6、88／89／95 enemy1、91 enemy5、94 三個 enemy5）。地圖 92 的核心在原版是 animap1 拼成的裝飾，和主線地圖 90 一樣不畫（主線複製的地圖都不畫 animap1 的樹、岩石）。

## 野外戰鬥背景

用共用的 `registerBackdrop`（`src/timeroom.js`，main 的 commit 6c811eb）：地圖 87～95 交給 `z3BackdropAt`（`src/z3.js`，Z3 起的 `set_battle_map` 地形規則，時之間裡變數 301 = 2）。
森林／林要看格子上的地圖事件，所以 `tools/build_tr_z4.py` 把這幾張地圖的事件寫進 `world.z3.tileEvents`（和主線地圖同一套：該格 id 最大的事件、第一頁的圖）。海、崖照變數 101。

- 頭目格是「站上去按按鈕」開打（原版踩上去就開打），打完站在原地可以再按一次重打（原版要離開再踩）。
- ~~HUD 只顯示「時之間」~~（batch2 viz 已做）：`trGoal` 在區域裡顯示原版 `story_string` 的區域名（變數 43 = 901～937，例如「時之間：威洛博士區域(蓋洛博士研究所)」，`world.viz.trArea`）。
- 輸掉頭目戰：照重製版其他戰鬥，回到最後的存檔（進區域時、旅館、卡片格、野外勝利都會存檔）。
- ~~9781 絕望的反抗、9791 另一個結局~~：第 3 階段已做（`src/tr_future.js`，docs/tr-future.md）。
- 地圖 86 寬 37 格，第 1 階段的區域門表在地圖 86 也放了 x = 38、43 的 9781／9791，走不到（無害）。
