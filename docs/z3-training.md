# Z3 修行小遊戲（`src/z3train.js`）

兩個小遊戲都照原版移植成直向手機版；第四章（`src/z3d.js`）照下面的參數呼叫。素材清單在 `tools/build_z3train.py` 的 `add(world, h, z3)`。
測試入口：`index.html?dev=z3pair`（流派一致修行，可加 `&pattern=0..3`）、`index.html?dev=z3gravity`（貝吉塔重力修行），面板隱藏時加 `&timer`。結束後會出現一個測試用的小面板（結果、修行前後等級、「再玩一次」）。
測試掛鉤 `window.__z3t`：`tick(n)`、`C()`／`B()`（原版的確定／取消）、`state`；流派一致修行另有 `pointCard(i)`、`pointChara(i)`、`cards = [...]`；重力修行另有 `yes()`／`no()`、`hp =`、`level =`、`cards = { mine, his }`。

## 呼叫方式（給第四章）

```js
import { ryuhaPairTraining, z3GravityTraining } from './z3train.js?v=…';
await ryuhaPairTraining(game);            // z1field 1302／1304／1306：pattern 0（悟空・悟飯・比克）
const r = await z3GravityTraining(game);   // z1field 1308：隊伍第一人（原版先設 $partyc = [12]、全員回復）
```

| 函式 | 參數 | 回傳 |
|---|---|---|
| `ryuhaPairTraining(game, opts)` | `pattern`：原版變數 121（`@chara_pattern`，沒給就用 `state.var[121] \|\| 0`）。0 = 悟空・悟飯・比克 `[3,5,4]`（Z3）；1 = 超貝吉塔・超特南克斯 `[19,20]`；2 = 超悟空・超悟飯 `[3,5]`；3 = 目前隊伍（`$partyc`，克林們）。<br>`makeCards`：預設 true = 先做 CE40「流派一致修行用カード生成」（原版每次呼叫前都做）；false = 用現在的手牌。 | `{ cleared: true, counts }`：這個修行不會失敗；`counts[k]` = 第 k 個修行者組隊的次數。 |
| `z3GravityTraining(game, opts)` | 不需要參數（修行者 = `state.party[0]`；`opts.member` 可以指定別人）。 | `{ cleared, level }`：`cleared` = 撐過 300 倍；`false` = HP 歸零（`level` = 當時的重力）。 |

兩個都會播自己的 BGM，結束時不停止（原版下一頁事件會自己換 BGM），淡入 10 格、淡出 20 格。**變數 41 不在這裡改**：

- 流派一致修行：原版事件頁 37 → 1302、頁 38（「怎麼也不順利啊…好！再試一次吧！」）→ 1304、頁 39（「好！我漸漸掌握訣竅了！…再努力一下！」）→ 1306，每頁都先呼叫 CE40 再進場景，回來後變數 41 + 1。這些台詞是第四章的頁面。
- 重力修行：原版成功時場景自己做 `$game_variables[41] += 1`（1309 → 1310 古拉到達）。失敗時變數 41 停在 1309 → 頁 41「ベジータ修行失敗！」：貝吉塔「可惡…　不行嗎…／但我一定會超越卡卡羅特的！」、`all_charecter_recovery`、變數 41 − 1 → 回到頁 40 再修行一次（從 100 倍重新開始）。所以第四章拿到 `cleared: false` 時：播頁 41 的台詞、全員回復，再呼叫一次 `z3GravityTraining`。

## 流派一致修行（原版 `all.rb` #118 `Scene_Db_Ryuha_Pair_Training`，約 155681 行）

規則（原版訊息，簡轉繁）：「從卡片中選出一組流派相同的／請選擇需要組隊的兩人！／可以一直選擇，直到沒有相同的為止！／注意，流派"必"是不算相同流派的！」

- 卡片：7 張（`$Cardmaxnum + 1`）。CE40：星數、防禦 `rand(8)`，流派 `create_card_i 0, true`（不出「必」）；這裡用 `newCard()`（`src/battle.js` 的 Z3 流派規則）重抽到不是 0。用掉的兩張用 `createcardval`（`create_card_i 0`，可能出「必」）補。結束時這 7 張留在手牌（前 6 張寫回 `state.hand`；原版在古拉到達時才 `allcardexchange`）。
- 流程（`@window_state`）：0 規則 → 1「組隊的人可以獲得經驗！　加油吧！」→ 2 選第一張牌（同流派的牌的流派圖示閃爍，`(32i, 240)`）→ 3 選第二張：流派不同或有「必」→ 15 結束（`Z1 完了`）；相同 → 4 選第一個人 → 5 選第二個人（不能選同一人）→ 6 對打動畫（`戦闘アニメ` 的閃光 50 格 → 兩人對打 260 格 → 閃光 50 格，第二個人左右翻轉）與該組合的台詞 → 7 兩張牌翻面閃 40 格後換新牌、兩人的次數 +1 → 回到 2。返回（B）：3 → 2、4 → 3、5 → 4。
- 組合台詞：pattern 0 不分順序（悟空＋比克、悟空＋悟飯、比克＋悟飯）；pattern 1／2／3 分順序（原版表），沒有的組合沿用上一次的台詞（原版就是這樣）。pattern 3「天津飯＋雅木茶」第二句的說話者原版寫成餃子，照原版保留。
- 結束台詞（15）：pattern 0 悟空「呼…　到此為止吧　不稍微休息一下嗎？」／比克「好吧…」等四種。
- 獎勵 `get_exp`（每個修行者，包含 0 次的人）：經驗值 = 等級 × 250 × 次數 × 3 ＋ 固定（pattern 0：25000；1：250000；2：350000；3：450000），再乘 `EXP_RATE`（8，同其他修行）。每人播 `Z3 経験値取得`、「X獲得N經驗值！」、升級時 `Z1 レベルアップ`（共通事件 188）「X升到N級了！」；必殺技使用次數：全部技能 +（pattern 0：3；1、2：10；3：5）＋ 次數 ÷ 2（取整），上限 99999，「全部必殺技的使用回數增加　N　回！」。經驗值給目前在用的形態（超級賽亞人時就是超賽那個角色，它保留經驗值）。
- BGM：pattern 0 `Z3 修行`；1～3 `ZSB1 天界のテーマ(GB音源Ver)`。音效：確定 `Z3 決定`（動畫中與 7 不響）、移動 `Z3 カーソル移動`、返回無音效（原版就沒有）。
- 原版的游標小怪癖照做：選第二個人時游標的右端用 `@training_select_chara.size − 1 = 1`，所以選完第一人後游標跳到第 2 人或第 1 人。

## Z3 重力修行（原版 `all.rb` #115 `Scene_Db_Z3_Gravity_Training`，約 153529 行）

規則（原版訊息）：「X的重力修行！／請調整卡片的星數為16！」「最多能抽兩張卡　但卡片都是自動抽取的！／比重力裝置的星數少　或者超過16都算失敗！／並且會受到傷害！」「從100倍重力開始！／每通過一次就提高20倍／最多可通過300倍重力！／HP為0時　會重新從100倍開始！」「一口氣全部通關吧！／修行開始了！」

- 牌：雙方各 3 張，星數 `rand(8)`、防禦 0。重力裝置先蓋著發兩張（每張 30 格），再發你的第一張（流派 = 修行者的流派）。
- 5「到X的回合了！要再抽一張卡嗎？」是／不是 → 6「卡片上的星數是　N／要再抽一張卡嗎？」是 = 第三張（三張合計超過 16 立刻失敗）。
- 7 等 60 格 → 10 重力裝置依兩張的合計決定要不要第三張（合計 ≤8：80%、9：70%、10：60%、11：40%、12：20%、13：15%、14：10%、15：5%、16：0%，`probability >= rand(100)`，所以 0% 也有 1%）→ 90 格後翻開 →「勝負！」60 格後判定：
  - 重力裝置 > 16 或 你 > 重力裝置 → 25 勝：「X克服了　N倍的重力！」（切入圖勝利姿勢、人物停住）→ 26「下次要挑戰　N+20倍的重力！」；100 倍與 200 倍過關時給經驗值 → 重力 +20，重新發牌。300 倍過關 → 28「太好了！　終於克服了300倍的重量！」→ 經驗值 → 結束（`cleared: true`）。
  - 相等 → 24「修行沒獲得有效的成果…」，重新發牌。
  - 你 < 重力裝置 → 22 `Z1 ダメージ`「X無法忍受　N倍的重力！／X受到　N÷10點傷害！」（受傷姿勢、切入圖受傷）→ HP − 重力÷10 → 23「可惡…　再　再來一次…！這種程度的重力我馬上就能克服…！」重新發牌；HP 0 → 27「X因受到過多的傷害而失去知覺了……」→ 結束（`cleared: false`）。
- HP 是場景內的複本（`@battle_hp = actor.hp`），不寫回角色。
- 經驗值 `get_exp`：100000 × (重力 ÷ 100)（100 倍 100000、200 倍 200000、300 倍 300000），再乘 `EXP_RATE`（8）；`Z3 経験値取得`、「X獲得了　N　經驗值！」、升級「X升到N級了！」。失敗重來時 100 倍、200 倍的經驗值會再拿一次（原版就是這樣）。
- 畫面素材：`Z3_修行_重力装置`、`Z3_戦闘_<名字>`（姿勢列 0～4 循環、17 受傷）、`Z3_味方カットイン`（第 actor−3 列，0 平常／1 受傷／2 勝利）、`カード関係`（Z3 卡面 `(512,96)`、卡背 `(576,96)`、重力裝置的流派「重」`(352,0)`）、`数字英語`（HP、G）。BGM `Z3 修行`（變數 40 = 0／1 時 `Z1／Z2 修行`）。
- 變數 38（戰鬥訊息自動前進）沒設時當 1：經驗值與升級訊息要點一下（原版 `input_loop_run`，不響確定音）；= 0 時 60 格自動繼續。
