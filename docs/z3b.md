## 流程（照原版順序）

1. **1440**（前一章結束時變數 41 = 1440、43 = 65）：比克修行、天神來訪 → 天界：卡里克二世占領神殿、魔族四天王 → 數日後龜屋：大家決定分頭偵察。
2. **分組（頁 59 的標籤「方角選択」）**：悟飯・琪琪・龜仙人選 東／西／南；雅木茶・天津飯選剩下兩個；克林・餃子走最後一個；比克確認「是／不是」，選「不是」重選。
   - 原版把方向寫進角色 1 的名字再用 `\N[1]` 顯示；這裡每個分支直接寫入方向字（`tools/build_z3b.py choosing()`），台詞不變。
   - 變數 314／315／316 = 6 東、4 西、2 南；開關 536～538。
3. 東（地圖 78 (63,6)）→ 西（79 (7,39)）→ 南（80 (22,38)）：每區由選了該方向的隊伍出發（`$partyc` 依變數 314～316），全員回復。
   各區的魔族站在原版的位置（地圖事件 EV069，`enemy6.png` 角色 0，朝向決定是誰：下 加素、左 塔多、右 比家、上 素茲），靠近就開始：
   1471 → 戰鬥 1472 → 1481；1491 → 1492 → 1501；1511 → 1512 → 1521。打倒後變數 41 = 變數 95（原版開關 128 的做法），概況 +1。
4. **1521**：南方結束後換北方：比克單獨（`$partyc = [4]`），貝吉塔出現並加入 → 地圖 81 (60,42)（變數 101 = 1）。塔多 (6,6)：1531 → 1532 → **1541**：九人會合 `[4,5,6,7,8,9,10,24,12]`（比克帶頭）→ 地圖 82 (46,42)。
5. **地圖 82**：卡林塔 (5～6, 1～3) → 1551（吉加、尼奇、桑修出現）→ 戰鬥 1556 → 1561（魔凶星、卡里克巨大化、四天王復活）→ 戰鬥 1565 → 1571（天神、波波平安）→ 變數 41 = 1230、CE180（時之間新區域、「通知！」卡）→ `nextZ3(game, 'z3b')`。
   亞奇洛貝 (30,26)：1583，第一次（開關 1311）說明「自由」技能（CE276）並給「亞奇洛貝」「加林仙人」「天神」「波波先生」卡；之後可再聽說明。
6. 劇情戰都用 `fight()`：戰前自動存檔，讀檔或輸了從那場重來（`resume` 收到 `{ ch: 'z3b', at: '1472' … }`）。頁面設定的加成開關（25 剩一人、26 HP 30% 以下…）傳給戰鬥，打完照 `reset_battle_flag` 清掉。

## 手機版的做法

- 場景（z1field）照原版的背景與頭像。原版一排寬 320 px 的頭像（四天王、龜屋九人、卡里克的三個手下）在手機上放不下，改成同樣排列、縮成 40 px。
- 頁面在劇情戰處切開（`split_battle`）；分組選擇是獨立一段過場，開頭重畫龜屋場景。
- 卡里克巨大化後（1562 起）對話框的頭像也換成巨大化的。
- 地圖 78～82 只取第 0～44 列（45～53 列原版是空白，54 列是控制事件）。
- 目標文字用原版概況的標題（`draw_story_so_far` 65～69）。

## 給 README 的章節說明（合併時整理進去）

**Z3 第二章 魔凶星篇**：卡里克二世復活占領天神的神殿。Ｚ戰士分成四隊偵察（悟飯組、雅木茶組選方向），依序打倒東西南北的魔族四天王（北方比克與貝吉塔），最後九人登上卡林塔，對決卡里克與巨大化的卡里克。跳關：`?dev=z3b`、`z3bwest`、`z3bsouth`、`z3bnorth`、`z3bkarin`。

## 原版有、這裡沒做的

- **概況（前情提要）選單與讀檔後的前情提要**：資料（`world.z3.recap['65'～'69']`＝CE110～114，場景 1011～1015 在 `src/z3b.js`）已由第二批 sys 和 Z3／Z4 其他概況一起接上（`src/sys.js`，`docs/sys.md` §4）。
- **時之間入口**：原版這幾張地圖的時之間入口本來就是註解掉的（`#elsif … #時の間`），不做。
- **戰鬥 BGM 解鎖（開關 713「劇場版BGM1 ver2」）**：第二批 sys 已照原版做出設定畫面的解鎖清單（`docs/sys.md` §7）。
- 「自由」技能：亞奇洛貝的說明全文照搬，但重製版目前沒有「自由」技能欄。

## 共用檔案的最小改動

- `src/chapter2.js` `rollArea`：遇敵數可依隊伍人數（`areas[map].size = { 人數: [最少, 最多] }`），用於「隊伍 2 人時 1～2 隻」。
- `src/field.js` 頭目圖：`bosses[].row` 選角色圖的朝向列（enemy6.png 一格四個魔族）。
