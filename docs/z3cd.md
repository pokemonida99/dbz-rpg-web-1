## 呼叫修行小遊戲（`src/z3train.js`）的參數

- `ryuhaPairTraining(game, { round, party: [3, 4, 5], pattern: s.var[121] || 0, v324: 36 })`：round = 1／2／3（z1field 1302／1304／1306），
  pattern = 原版 `@chara_pattern = $game_variables[121]`（0：悟空一組），v324 = 頁 1298 設的變數 324。呼叫前隊伍已經是 `[3,4,5]`。
  回傳值不影響流程（原版三次都會往下走）。
- `z3GravityTraining(game, { party: [12], times: 300, tries })`：tries = 第幾次重試（0 起）。回傳 `{ cleared: false }` 就播頁 1309 再呼叫一次，
  `{ cleared: true }` 進頁 1310。呼叫前隊伍已經是 `[12]`。
- 兩個都在呼叫前存檔，讀檔會從那次修行重新開始。結束後這章會自己 `begin(game)` 接著播劇情。

## 原版有、這版沒做或做法不同

- 1241／1255 的戰鬥動畫：原版是特定的攻擊動作（187 閃耀劍擊、182 等），這版用現有的 Duel 動畫（閃耀劍擊沒有專用動畫，播一般攻擊）。
- ~~地圖 36 太空船降落的「動畫 4」以畫面震動代替~~（batch2 viz 已做）：動畫 4「宇宙船到着1フレ」（Z3_爆発，加算）照原版在太空船上播兩次、間隔 30 格，畫面同時震動 60 格（`world.viz.anims`、`src/vxanim.js`）。
- 頁 40／41 的重力修行失敗時，原版會先顯示「貝吉塔正在超重力下進行修行！」再進修行（事件直譯器與場景切換的時間差）；這版重試時直接進修行。
- 地點的先後：原版的格子路線讓玩家依序經過門衛／凱澤；這版自由飛行，所以地圖 37 的基地要先打倒門衛（開關 419）、
  地圖 38 的凱澤要等人質全救出（近道開放）、基地要先打倒凱澤（開關 421）。
- 神龍願望中「神探測器」（開關 490）、「波倫加升 S 級」（491）、「卡片最大持有數 8／9」（494／495）、「ZP 2～5 倍」（496～499）、
  「每張卡都能走 8 格」（1320）：開關照原版設定，但這版還沒有對應的系統（探測器、卡片上限、格子移動），所以目前沒有效果。
- ~~卡片 48（未來特效藥，頁 1256）與 38 拿不到~~：兩張現在都在 `world.items`，效果在 `src/cards_story.js`。
- ~~時之間入口（地圖 38 (11,25)、39 (37,21)）~~：已接上（`world.pois` 的「時之間」）。
