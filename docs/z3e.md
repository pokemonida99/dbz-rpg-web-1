## README 用的章節說明

> **Z3 第五章 人造人間**：人造人出現的日子，布瑪帶著嬰兒特南克斯、亞奇洛貝送來仙豆。地圖 40 上找出 20 號（停下時路人會指出可疑的方向）；悟空心臟病發作，琪琪或龜仙人替補。19・20 號 → 特南克斯回來加入 → 研究所 → 17・18 號、16 號（輸了劇情照樣進行）→ 比克與天神融合、單挑沙魯（撐 4 回合）→ 太陽拳、片尾 →「Z3 完」（Z4 待續）。
> 開發用跳關：`?dev=z3e`（頁 1326 開始）、`z3efield`（地圖 40，心臟病前）、`z3elab`（20 號打完、研究所前）、`z3e17`（17 號前）、`z3ecell`（頁 55 融合 → 沙魯戰）、`z3eend`（頁 56 → 結尾）。

## 流程（照原版）

1. **頁 46（1326）**：關超賽（1、3）→ 隊伍 `[3,4,5,6]` → 1327～1331（布瑪、嬰兒特南克斯、亞奇洛貝、仙豆、氣墊車爆炸）→ 隊伍 `[3..9]`；CE14（龍珠清掉）、CE180（時之間＋通知卡）、**變數 308／309 = 64／13（20 號的位置，就是這一頁設的）**、概況 +1 → 地圖 40 (5,56)。
2. **地圖 40 停下時**（原版：每次移動後檢查停下的格子，不是特殊格就走 `else`）：
   - 開關 428（用過未來的藥）、434（心臟病已發生）都沒開 → **1335 心臟病**：悟空離隊，開關 555 → 琪琪（1337），否則龜仙人（1338）加入；開關 434。
   - 還沒找到 20 號（開關 426）→ `rand(3)+1 == 1`（三分之一）→ **1421 方位提示**：z1field 1421 依目前位置與 (308,309) 算出變數 310（九宮格方向），路人隨機（變數 307：大叔／少年／大嬸，Z3_顔イベント 第 0／1／4 列）。
   - 手機版的「停下」：放開搖桿、且自上次判定後飛了 3 格以上、不在任何地點旁邊（原版是用卡片移動、每步停下都會判定）。
3. **(64,13) 20 號**（地圖上原版就沒有圖，所以是「調查這一帶」）→ 頁 48（1341，貝吉塔加入、+200000 EXP）→ **戰鬥 1342**（開關 25、26 的追加攻擊）→ 頁 49（1351）特南克斯加入、學會技能、Z 戰士之絆。輸了 → 讀戰前存檔（原版沒設變數 239）。

## 手機版的調整

- Z3 的場景圖是 512×128，手機只看得到中間約 230 像素：橫排超過的臉（1328 的五人、17・18・16 號三人）照原版順序拉近，必要時縮小。
- 全螢幕的演出（1385 氣、1386／1405～1412 剪影、1389 沙魯登場、1402～1404 太陽拳）：剪影條放在場景框下面（原版的 480−192 位置），其他放進場景框。1384 的「變暗」用建置時產生的 `assets/bg/z3e_tenkai_1/2.png`（Tone −85／−170）。
- 戰鬥招式名稱（資料庫只有日文）：能量波、強力能量波、連續能量波、吸取生命、龜派氣功、魔貫光殺砲、太陽拳（照之前章節的譯法）。
- 台詞全文保留（`tools/s2t.py`）；原版寫「特兰克斯」的地方照原文（特蘭克斯），頭像對到特南克斯。

## 原版有、這裡沒做的

- **時之間的格子** (24,10)(10,54)(68,15)：時之間還沒做（docs/z3-plan.md）。
- **卡片特殊（變數 44 = 30）的獎品範圍**：`src/cardgames.js` 目前只用 Z1 的獎品表（`create_get_card` 不看變數 44），所以和一般卡片格一樣；這裡已設好變數 44，等共用的卡片格支援。
- **未來的藥（卡片 48）**：原版給悟空用了會開開關 428、心臟病不發作；重製版的道具卡還沒有這張（第三章／共用的 items），所以心臟病一定會發生。開關 428 一開，這章就照原版跳過心臟病。
- CE173／174（倍速不可／可）：重製版沒有倍速。
- 1384 天神與比克合體時的半透明：只做移動與最後只剩比克（原版最後也是比克蓋在上面）。
