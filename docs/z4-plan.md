## 共用基礎（z4-base 分支，已完成）

- `tools/build_z3.py`：Z4 的劇情戰（上表全部）、Z4 敵人（威洛(強)、賽魯各形態、小賽魯、金屬古拉、機器人兵、13～15 號與原型）、Z4 地圖的 `tileEvents`（戰鬥背景自動選）、
  頁面轉換 `z3['page4'](v)`（事件 7 的頁）／`z3['raw4']`，其餘工具同 Z3（`nodes_of`、`split_battle`、`file`、頭像表）。各章的 `tools/build_z4?.py` 的 `add(world, h, z3)` 由 `build_z3.py` 呼叫。
- `src/z3.js`：`ORDER` 加上 `z4a`～`z4f`、`hasChapter(key)`；`src/z3e.js` 的 Z3 結尾在 `z4a` 註冊後接進 Z4；`src/main.js` 載入 `src/z4a.js`～`z4f.js`，`?dev=z4…` 交給各章的 `dev()`。
- 其他照 `docs/z3-plan.md` 的「共用基礎」「交接約定」：`registerZ3('z4?', { maps, start, spot, boss, resume, dev, goal })`、`fight(game, 編號, 續玩鍵, { turns, dmgRate, stopWhen, foeHp })`、
  `nextZ3(game, '自己的鍵')`、頁面一律用 `z3['nodes_of']`／`z3['page4']`（迴圈、變數比變數、CAP 都處理好了）、場景用 `addScenes`、戰鬥背景自動選。
