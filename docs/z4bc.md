# Z4 第二章「悄悄接近的賽魯」・第三章「新生貝吉塔父子出擊」（`z4b`・`z4c`）

程式：`src/z4b.js`（第二章，也放兩章共用的場景、戰鬥動畫、賽魯變身、戰鬥）、`src/z4c.js`（第三章）；

## 共用與協調

- **地圖 44（精神時光屋）三章共用**（z4a：變數 121 = 1、z4c：2、z4e：3）：由主 session 的 `tools/build_z4a.py` 統一定義（地圖、卡片格 (11,8)、旅館 (4,4)、
  修行開始點 (15,4) `{chapter: 'z4', page: 'htc'}`）。`src/z3.js` 的 `z3Spot` 把 chapter 'z4' 交給目前這一章，`src/z4c.js` 的 `spot()` 在
  `poi.page === 'htc'` 且變數 121 = 2 時接（頁 2331）。`build_z4c.py` 只用 `setdefault` 放一份同樣的替身，z4a 合併前測試用，合併後以 z4a 的為準。
- 新角色（`world.actors.setdefault`）：18 號（21）、17 號（22）、16 號（23），能力照資料庫；招式名稱（能量波、多重能量波、強力能量波、火箭飛拳、地獄閃光、
  賽魯第二形態的招式）照之前章節的譯法。超級貝吉塔（19）、超級特蘭克斯（20）沿用 Z3 已有的。
- 戰鬥動畫的招式影片（`addMoves`）：沒有原版專用影片的借最接近的（同 Z2／Z3 的做法）。

## 原版有、這裡沒做或做法不同

- **戰鬥的開關 121～125**（不記錄戰績、不掉卡、不算擊破數、不給經驗值、不記錄最大傷害；戰鬥 2256 開了 122～125）：重製版的戰鬥（`src/battle.js`）
  還沒有這些開關，所以打贏 2256 照樣有經驗值和掉卡。要做的話是共用檔案的改動，交給主 session 決定。
- **戰鬥服、長髮等外觀**（變數 171～173、開關 131／132／438／443／445）：開關與變數照原版設定；場景裡的臉照 `set_character_face` 換，
  但戰鬥圖與地圖上的角色重製版還沒有換裝系統，維持原本的樣子。
- **原版地圖 43 的卡片格 (77,37)**：在 65 格寬的地圖外（從地圖 42 複製過來的），原版也走不到，沒加。
- **set_battle_event 8（2301 賽魯反擊）**：頁 19 直接把變數 41 設成 2311，原版走不到，沒做。
- **時之間入口**：時之間還沒做。
- 戰鬥動畫裡敵人的攻擊動作（`@tmp_ene_set_action`）用一般攻擊的影片。
