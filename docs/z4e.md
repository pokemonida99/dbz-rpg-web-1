# Z4 第五章 人造人間 13 號（`z4e`）

程式：`src/z4e.js`；資料：`tools/build_z4e.py`（由 `tools/build_z3.py` 呼叫，寫進 `world.z3.pages['z4e…']`、`world.z3.z4e`、地圖 93）。
地圖 44（精神時光屋）由第一章的 `tools/build_z4a.py` 統一定義（卡片 (11,8)、旅館 (4,4)、修行開始 (15,4) 的地點 `{chapter: 'z4', page: 'htc'}`）；這章的 `spot()` 在變數 121 = 3 時接手 `htc`。z4a 合併前，`build_z4e.py` 用 setdefault 先放一樣的定義供測試。

## README 用的章節說明

> **Z4 第五章 人造人間 13 號**：悟空把丹迪帶回地球，大家各自回家；天津飯他們在神殿碰頭，四個地球人一起進精神時光屋（地圖 44，到右上方開始流派一致修行）。修行完的幾天後，悟空一家上街購物時 14・15 號來襲（悟空單挑的戰鬥演出），Z 戰士與修好的 16 號會合 → 地圖 93：打倒 15 號、14 號後 13 號甦醒 → 13 號 → 吸收零件合體 → 合體 13 號 → 比克、貝吉塔、桃白白、牛魔王各自的後日談 → 交給第六章（賽魯遊戲）。
> 開發用跳關：`?dev=z4e`（頁 2371 開始）、`z4eroom`（地圖 44，修行前）、`z4eshop`（修行後：頁 2801 → 地圖 93）、`z4efield`（地圖 93 剛到）、`z4e13`（14・15 號打完、13 號前）、`z4eend`（合體 13 號打完：頁 2881～2931 → 下一章）。

## 流程（照原版）

1. **頁 22（2371）**：丹迪回地球、龍珠復活、大家各自回家（`character_output_all` 模式 2／3／4）→ 變數 41 = 2941。
2. **頁 70（2941）**：天津飯他們到神殿，隊伍 `[6,7]` → `[6,7,8,9]`，波波帶他們進精神時光屋；變數 43 = 94、121 = 3、42 = 6 → 地圖 44 (9,8)。
3. **地圖 44 (15,4)** → 頁 71：`ryuhaPairTraining(game, { pattern: 3 })`（CE40 由小遊戲發牌）→ 變數 41 = 2801。修行前自動存檔，讀檔從修行重來。

5. **頁 56（2821）**：悟空引開人造人、Z 戰士與 16 號會合；比克 +500000 EXP、隊伍 `[3,4,5,6,7,8,9,12,17]`、CE180、變數 43 = 92 → 地圖 93 (60,29)。
6. **地圖 93**：15 號 → 頁 57 → 戰鬥 2832；14 號 → 頁 59 → 戰鬥 2842；兩個都打倒時變數 43 + 1、→ 頁 61（2846）13 號甦醒。輸了 → 讀戰前存檔（原版沒設變數 239）。

## 手機版的調整

- Z3 的場景圖是 512×128，手機只看得到中間約 230 像素：場景裡的臉照原版位置，太寬時拉近或縮小（2803 的三盤菜）；`character_output_all` 的 11～12 人一排五個、縮小。
- 頁 56 的 `$partyc = [3,14,4,5,18,…,23]` 只是為了把全員回滿：重製版一個角色只有一個成員（超賽形態算同一人），16 號沒有可操作的角色，所以略過；真正的隊伍照下一行。
- 2863 零件合體：重製版的場景圖沒有透明度，零件滑進去後在最後一格消失（原版邊滑邊淡出）。
- 13 號的標記在劇情開始時就消失（原版 14・15 號靠頁面先開的開關消失，13 號同樣處理），所以輸掉合體 13 號後讀檔會從那一場重來，不會在地圖上再碰到 13 號。
- 敵人招式名稱（資料庫只有日文）：能量波、全力能量波、連續能量波、爆發波、沉默刺客13、致命突襲、SS 致命炸彈、全力 SS 致命炸彈、人造人衝鋒14、人造人打擊15（照之前章節的譯法）。
- 台詞全文保留（`tools/s2t.py`）；原版寫「特兰克斯」照原文（特蘭克斯），頭像對到特南克斯。
