# Z4 第六章 賽魯遊戲（`z4f`）

程式：`src/z4f.js`；資料：`tools/build_z4f.py`（由 `tools/build_z3.py` 呼叫，寫進 `world.z3.pages['z4f…']`、`world.z3.z4f`、地圖 48）。

## README 用的章節說明

> **Z4 第六章 賽魯遊戲**：命運的第 17 天（悟空家、神殿、岩山、16 號加入）→ 地圖 48 走到擂台：撒旦先上場（踢擊動畫）→ 悟空單挑賽魯（撐 10 回合）→ 悟飯上場（變超賽、撐 7 回合）→ 16 號 → 16 號被破壞、悟飯覺醒成超級賽亞人 2、一掃小賽魯 → 賽魯吐出 18 號、自爆、悟空犧牲 → 完美賽魯＋小賽魯（九人總決戰）→ 龜派氣功對決（原版圖片演出：眾人加入、貝吉塔、親子龜派氣功）→ 天界、神龍、特蘭克斯回未來 → 片尾工作人員名單 → 龜仙人「還有一點點」→「Z4 完」（ZG 待續）。
> 開發用跳關：`?dev=z4f`（頁 2991 開始）、`z4fring`（地圖 48，撒旦前）、`z4fcell`（撒旦後、擂台旁）、`z4fgohan`（頁 2471 → 悟飯戰）、`z4f16`（頁 2491 起）、`z4fawake`（頁 2511 起）、`z4flast`（頁 2541 → 最終戰）、`z4fbeam`（頁 2571 → 龜派氣功對決）、`z4fend`（頁 2591 → 結尾）、`z4fstaff`（頁 2602：片尾名單）、`z4fall`（通關後：全員對戰的選項 → 2621）。

## 流程（照原版）

1. **頁 72（2991）**：前情、悟空家（琪琪、牛魔王、瞬間移動 CE36）、神殿、岩山（貝吉塔、特蘭克斯、16 號）→ 隊伍 `[3,4,5,6,7,8,9,12,17]`、CE180、變數 43 = 95 → 地圖 48 (75,63)。
2. **擂台 (44,35)**（地圖 48 事件 6 的賽魯圖）：
   - 開關 457 沒開 → **頁 29（2441）**→ 2449 撒旦踢擊（演出）→ **頁 30（2451）**→ 回到 (44,36)。手機版：離開擂台再走回去才會再觸發（原版是再踩一次 (44,35)）。
   - 之後 → **頁 31（2461）**：CE166 暫存隊伍；開關 458（通關過）才有小賽魯與「全員一起打嗎？」→ 是：**戰鬥 2464** → 頁 40（2621）結局；否／第一次：悟空單挑 **戰鬥 2463**（10 回合，變數 94）。
3. **頁 32（2471）**：撐過或打倒（開關 143）兩種台詞；CE167 還原隊伍；悟飯變超賽（CE57）→ **戰鬥 2481**（7 回合、敵人傷害 ×0.5）。
4. **頁 33（2491）**→ 2501 16 號（演出）→ **頁 34（2511）** 16 號被破壞、悟飯覺醒（CE58、超 2）、小賽魯被一一打倒 → 2531 超 2 悟飯對賽魯（演出）。
5. **頁 35（2541）**：18 號被吐出、賽魯自爆、悟空帶到界王星、完美賽魯、特蘭克斯被擊中、`add_cha_last_cellbtl`（補滿九人）→ **戰鬥 2561**。
6. **頁 36（2571）**→ **地圖 49 龜派氣功對決** → **頁 38（2591）** 悟飯昏倒、撒旦的訪問、天界（神龍召喚、許願）、悟空家 → **頁 39（2602）** 膠囊公司、特蘭克斯回未來、旁白 → 2691 片尾名單 → 通關變數（變數 2 = 34、開關 458／460／194、變數 84 = 3、變數 43 −1、超悟飯學會超賽變身 59、CE180）→ 2693 龜仙人「還有一點點」。
7. **Z4 結尾**（照 `src/z2b.js`／`src/z3e.js` 的 `ending`）：`flags.z3 = 'done'`、存檔、「Z4　完」卡 → 標題畫面列出原版接下來開放的內容（ZG 待續、時之間新區域、時之間和賽魯的戰鬥有變化）。

戰前自動存檔：2463／2464／2481／2561，讀檔或輸了從那場重來（`resume`）。

## 手機版的調整

- Z3 的場景圖是 512×128，手機只看得到中間約 230 像素：橫排超過的臉照原版順序拉近、縮小（神殿 10 人、小賽魯 8 隻等）。
- 原版放在場景框上方的臉（2433／2434 的波波在丹迪上方、2513／2516／2517 的超悟飯在小賽魯上方）：波波放在丹迪旁邊；超悟飯放在場景下方第一排，其他人從下一排開始。
- `character_output_all` 的大量頭像：超過 10 人時一排 6 個（36 像素），最多兩排，訊息框才放得下。
- 龜派氣功對決與片尾名單：在原版 640×480 畫面上照原版座標畫，縮放到螢幕寬度（對話時放在訊息框上方）。對決的並行處理（事件 2）每格照原版執行。
- 神龍召喚（2597）：`Z3_シェンロン呼び出し(天界用に編集)` 9 格照原版的格數與音效。
- 台詞全文保留（`tools/s2t.py`，13 頁逐字比對過）；原版頁 2591 一處「主持有」的錯字照原文，頭像對到主持人。
