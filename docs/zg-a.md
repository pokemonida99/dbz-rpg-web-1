## ZG 三段的約定（主 session 同意，zgb／zgc 照這個做）

- **隊員**：演員 25／26（未來悟飯）、27～30（巴達克一夥）、32（超巴達克）由 `tools/build_zg_a.py` 正式定義（圖、必殺技圖、招式、`addMoves`），
  其他分工只在缺的時候補最小定義，合併後以 zga 為準。招式 245 是超賽變身（`ss`，25 → 26）。
- **時之間的隊伍**：頁 6001 的 CE166 存進 `state.flags.zgParty = { party: [ids], ss }`。ZG 結束（頁 6761 → 9932，zgc）呼叫 `restoreParty(game)`。
- **中途回時之間（頁 9932）**：呼叫 `leaveZg(game)`（CE171：位置（y − 1）、變數 43／17、ZG 的隊伍與超賽狀態存進
  `state.flags.zgBack = { key, map, x, y, v43, v17, party, ss }`，變數 371～375 也寫；CE182；時之間的隊伍放回；開關 78 ON、19 OFF；
  變數 17 = 0、43 = 999；回地圖 96 (18,3)）。
- **從門 9931 回去（開關 850 且有 `zgBack`）**：門把時之間的隊伍再存進 `zgParty`、換回 `zgBack` 的隊伍、全員回復、變數 43／17 還原，
  然後 `startTrStory(game, zgBack.key)`。各段的 `start()` 一開始呼叫 `backToZg(game, '自己的 key')`：是自己的就清掉 `zgBack`、回到那個位置、回傳 true。
- 開關 586 的「從暗黑星球區域開始」也照這個做：門設好 `zgBack = { key: 'zgc', map: '110', x: 2, y: 21, … }` 後 `startTrStory(game, 'zgc')`。
- 以上都從 `src/zg_a.js` 匯出：`keepParty`、`restoreParty`、`leaveZg`、`backToZg`。

## 和原版不同、或沒做的地方

- **卡片流派**：原版變數 43 = 143～149 時我方卡片再排除 龜・界・魔・造（Z2 段另外排除 超，只剩 必／惑）。主 session 已改在
  `src/battle.js`（main 的 commit 64730c2），本分支 cherry-pick 了。進這段時手上原本的卡不換（原版也沒有換牌）。
- **戰鬥動畫**：一夥的新招式（火焰狙擊、狩獵之箭、憤怒加農、巨型加農等）、超巴達克的超級復仇標槍、敵人（阿比・金卡恩、達列斯軍、
  史拉格軍、弗利薩(全力) 391～395）的招式，用 `addMoves` 對到最接近的現有動畫（同 `src/z2b.js`、`src/z4*.js` 的做法），不是逐格移植。
- **大猿變身**（251／262／270／278）不放進一夥的招式：重製版沒有我方大猿狀態。
- **被動技能「最終決戰改」**（頁 6131 `set_typical_skill` 670）：第一批小修正 pas 接上了（節點 `zgaTypical`，巴達克固有技能第一格，`docs/pas.md`）。
- **地圖 100～102 用走路圖**（`walk: true`）：原版這三張是走路（主人公事件 chara1 第 6 個），一夥也沒有飛行圖。
  地圖下方原版只有空白與控制事件，重製版只取有圖的列（100：29 列、101／102：32 列），手機上不會看到大片黑色。
- 遇敵頻率用重製版共通的步數；修行格原版就註解掉了。
- 對話框頭像：原版這些頁沒有頭像，重製版照說話的人加上（Z2 段用 Z2 圖、未來的悟飯／布爾瑪用未來版；「？」「男」不加）。
- 劇情戰前先存檔，打輸讀檔會從那場戰鬥重來（原版是 Game Over）。
- 視窗外觀（`set_skn`）、CE160（大猿解除）不需要。
- `zgb` 還沒合併時，6171 結尾會顯示「尚未製作」，玩家留在地圖 100（這是預期的）。
