## 給其他分工的交接約定

- **zga → zgb**：頁 6171 最後 `startTrStory(game, 'zgb')`。我的 `start` 會自己設好隊伍、變數、位置（見上），zga 不用先移動。
- **中途回時之間（頁 9932）→ ZG 大廳的門（頁 6000，開關 850 開著）**：`state.flags.zgBack = { key, map, x, y, v43, v17 }`；
  門那邊在開關 850 開著且有 `zgBack` 時呼叫 `startTrStory(game, zgBack.key)`，那段的 `start` 看到自己的 key 就回到那裡（本段已這樣做）。
  原版 9932 還會跑 CE157／CE168（劇情隊伍與時之間隊伍互換），隊伍的暫存是 zga 在頁 6001（CE166）做的，所以互換留給 zga 決定怎麼接；本段目前不換隊伍。
- **地圖 105 與 zgc 共用**：本段的劇情格都加了 `when: ['var', 43, 173, 4]`（變數 43 < 173）；卡片格、修行格、旅館兩邊一樣。zgc 加自己的格子時請**附加**到 `world.pois['105']`，不要整個覆蓋；地圖本身兩邊建的一樣。
- **角色 25、26、27～30、32**：zga 先定義；本段只在不存在時補（同樣的寫法）。另外 `start` 會照 CE9 補上 18／17／16 號（Z4 建的沒有招式）、未來悟飯與多瑪等人的基本招式。

## 和原版不同、或沒做的地方

- **鳥的移動**：地圖事件畫不了 96×64 的 `!bigsize_anime`，本段在 `src/zg_b.js` 包了 `Field.prototype.drawEvents`（只在地圖 103 加畫鳥、檢查鳥的區域）。飛走時照原版速度 4、往右下 14 格，期間不能操作。
- **村子的選單**：原版是對話框裡的選項。共用的 `choice()` 會把三個選項直排在對話框下面，375×667 時掉到畫面外，所以本段在選單前先收起對話框、選項橫排在畫面下方（只影響本段的選單）。建議主 session 之後統一改共用的 `choice()`。
- **手電筒（卡片 127）、冷凍膠囊（128）**：重製版沒有這兩張卡（卡片圖示表在共用的 `build_items.py`），只照原版顯示「借來了手電筒！」等台詞，劇情由開關 813／821 判斷，結果相同。
- **達列斯的大猿變身（技能 644）、史拉格的巨大化（645）**：重製版戰鬥沒有敵人變身（只有貝吉塔的 373），先從他們的招式裡拿掉。
- **巴達克一味的大猿變身（251／262／270／278）**：重製版隊伍沒有大猿狀態，CE9 的這幾招不補。
- **戰鬥動畫**：新招式先用最接近的既有動畫（`addMoves` 對照表在 `src/zg_b.js` 開頭），還沒照經典版逐格移植。
- 「\^」（自動關閉的訊息）：重製版沒有自動關閉，弗利薩等人登場的四句要點一下；只有「\^」的空白訊息省略。
- 敵人名稱照資料庫保留「(強)」（同時之間第 2 階段的寫法）。
- 原版開關 80（多人顯示）、`set_skn`（視窗外觀）、CE160（大猿解除）不需要。
