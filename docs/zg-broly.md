## 重製版的做法

- 兩篇都是 `src/z3.js` 的章節（`registerZ3('zgbroly' / 'zgeob')`），門用 `registerArea(9902 / 9921)`，開始 `startTrStory`、結束 `endTrStory`（`state.flags.z3` 劇情中是這篇的 key，讀檔會回到這篇）。
- 頁面照 Map007 的方式一頁接一頁播（每頁結尾設好下一頁的變數 41）；`battle_process` 的編號就打那場戰鬥（`fight()`：戰前存檔，打輸讀檔從那場重來），贏了變數 41 = 變數 95。
- 隊伍暫存（CE166／167／168）：`state.flags.zgb.tmp[變數 22] = { ids, ss }`；換回時先照當時的超賽狀態同步（CE157，`syncSuperSaiyan`）再排隊伍。角色本身（等級、技能）和主線共用，跟原版一樣。
- 場景：`tools/build_zg_broly.py` 直接從 all.rb 讀 z1field（`picture`／`rect`／`add_chr`／`set_character_face`／`character_output`／`character_output_all`），`src/zg_broly.js` 照原版位置畫；`set_character_face` 照衣服變數換臉（變數 171～177、開關 363／388／445，巴達克 175）。
- 劇情戰的背景、戰鬥曲照 `battle_process`（5111「ZArrang_btlブロリー」、5131「バーニングファイト」）。
- **布羅利的招式動畫**：イレイザーキャノン（超／全力）、イレイザーブロウ、スローイングブラスター、オメガブラスター照原版 `anime_pattern` 2624／2630～2633 逐格移植（每格的位置、移動量、姿勢、音效、球的大小顏色、氣的背景、オメガブラスター的圖與超龜派氣功的線、白光），寫成 `Duel.prototype` 的方法（`src/zg_broly.js`，沒改 `src/anime.js`），用 `addMoves` 接上；普通的能量波／連續能量波／強力能量波／爆發波用之前章節最接近的動畫。戰鬥員的能量波同。
- 跳關：`?dev=zgbroly`（大廳、熱戰的門）、`zgbroly2`（中途離開後再進門）、`zgbrolyfield`（地圖 56、布羅利旁）、`zgbrolyboss`（直接 5101）、`zgeob`（Episode of Bardock 的門）、`zgeobfilm`（從 5791 開始），都加 `&timer`。

## 和原版不同、或沒做的地方

- **戰鬥影片 5801**（原版是約 300 行的專用動畫，動作 165）：用戰鬥畫面的動畫代替——超巴達克的招式用ファイナルリベンジャー（之前章節對應到ギャリック砲的動畫）命中齊爾德一次。
- ~~超巴達克（演員 32）重製版還沒有~~：演員 32 已在 `world.actors`（`Z3_戦闘_バーダック(超)`），`src/supersaiyan.js` 的 FORMS 7 = 16 → 32，`on_super_saiyazin 7` 照原版換人。
- 布羅利招式動畫裡原版的角色切入畫面（`@chr_cutin_flag`）與縮小背景（`@tec_back_small`）沒做；球的閃爍照每 4 格換一張。
- 戰鬥前的曲（變數 319 = 0 時的「戦闘準備」）沒有另外播，戰鬥曲直接用 319 = 0 的那首。
- 對話框的頭像：原版這些頁沒有，重製版照說話的人加上（布羅利照當時的形態；「異星人」「異星戰士」照那一頁是誰）。敵人招式名稱原版資料庫只有日文，イレイザーキャノン等四招的中文名是重製版取的（毀滅砲、毀滅衝擊、投擲光彈、終極爆破）。
- 場景裡的臉：一排太寬時縮小靠近（手機只看得到中間約 230 px）；場景裡上下兩排（`@ene1_y − 64`）各縮成 60 px 放進 128 px 的視窗；Z2 的 216×170 圖往上移 21 px（同 `src/z2a.js`）。
- 劇情戰打輸：讀戰前的存檔重打（原版是 Game Over）。
- 原版在時之間裡的小地方照做：9903 把開關 78 關掉（時之間裡筋斗雲卡變得能用）、EoB 結束後變數 175 留在 1（之後的場景巴達克是沒有探測器的臉）。
- 齊爾德（敵 238）只放在影片的資料裡，沒有加進 `world.enemies`（之後的分工要打他時再加）。
