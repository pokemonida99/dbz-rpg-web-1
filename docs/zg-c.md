2. **地圖 105 布布克島**：村 6431（姐姐／男孩子（開關 826）／離開，選單會重複問）、洞穴 6441、礦山 6451（皮拉夫一夥，開關 827）、火山 6471、別墅 6461（紫晶石）→ 6481 布爾瑪家（CE92 宇宙船發進、宇宙風暴、界王）→ 地圖 108 (52,39)，變數 43 = 175。
3. **地圖 108 克恩星**：派瑞之城 6491（派瑞人１：開關 829；派瑞人２：開關 832 後用紫晶石換星之貝殼、開關 833）、預言者之塔 6501（830 → 洞穴；回來後給紫晶石、832）、洞穴 6511（開關 830）→ 戰鬥 6516 → 6521（破魔的指環）。開關 833 一開：海盜船動畫（地圖 108 事件 88）→ 開關 834 → 6531 → 地圖 109 (5,5)，變數 43 = 181。
4. **地圖 109 奧特星**：海盜船 6541（835；淚之書 838）、庫阿鎮 6551（開關 835，選單；836）、漩渦 6561（837；有淚之書時 → 戰鬥 6566 齊爾德）→ 6571（破魔的珍珠、黑暗行星的聲音）→ 地圖 110 (2,21)，變數 43 = 186。
5. **地圖 110 暗黑行星**：護衛機器人 A～E（頁 6611～6615，開關 840～844）→ 戰鬥 6616 → 6621（CE93：五台都打倒 → 開關 845，門打開、遇敵換一組）；門 (28,18) 6601 在那之前擋住；怨念增幅裝置 6631 → 戰鬥 6641 → 6651（CE94 哈奇亞克）→ 戰鬥 6671 → 6681 → 戰鬥 6701 → 6711（CE69 變身）→ 戰鬥 6721 → 6731 → 6751（CE95）→ 6761（大家回自己的時代、集合圖「END」、開關 586 開、850 關）→ 頁 9932 → `endTrStory` 回 ZG 時之間大廳 (18,3)。
6. 各地圖的卡片格、修行格、旅館照 `Event_Check`；地圖 110 (26,13) 是「卡片特殊」（變數 44 = 50）。

## 和 zga／zgb 的約定（主 session 定案；筆記資料夾 `zg-a.md`「最後版」）

- **地圖 105** 兩段共用：地圖、卡片／修行／旅館格、遇敵誰先建誰的有效（相同內容）；劇情格各自追加，zgc 的有 `when: ['var', 43, 173, 0]`，zgb 的是 `['var', 43, 173, 5]`。遇敵在變數 43 = 173 時換成這段的一組（`areas['105'].late`）。
- **隊員 25、26、27～30、32**：由 zga 在 `tools/build_zg_a.py` 正式定義；這裡只在缺的時候補最小定義（同 `tools/build_z4f.py` 補 18／21／23 的寫法），讓跳關能單獨測。
- **共用的隊伍／回程工具在 `src/zg_a.js`**（`keepParty`、`restoreParty`、`leaveZg`、`backToZg`）。本檔用 `import * as ZGA` 讀，所以合併前（zg_a.js 還是空殼）也能單獨跑：沒有那些函式時用本檔裡步驟相同的備援。
  - 時之間的隊伍：頁 6001 CE166 存在 `state.flags.zgParty = { party, ss }`；結尾（6761 → 9932）`restoreParty(game)` 還原後 `endTrStory` 回 (18,3)。
  - 中途回時之間（「時の間へ移動」格）：`leaveZg(game, dy)` 存 `state.flags.zgBack = { key: 'zgc', map, x, y, v43, v17, party, ss }`（變數 371～375 也寫；位置照 Event_Check 移開一格：105／108 y−1、109 y+1、110 x+1）。
  - 門 9931（開關 850＋`zgBack`）換回 ZG 隊伍後 `startTrStory(game, zgBack.key)`；本段 `start()` 開頭 `backToZg(game, 'zgc')` 回到那個位置、清掉 `zgBack`。開關 586 後的「從暗黑星球區域開始」也是門設好 `zgBack`（地圖 110 (2,21)）再走同一條路。

## 和原版不同、或沒做的地方

- **戰鬥動畫**：新敵人（齊爾德、戈特加登、萊奇、哈奇亞克、奧佐特、ZG 雜兵）與未來悟飯、巴達克一夥的招式，照前面各章的做法用最接近的既有動畫（`addMoves`），沒有逐格移植原版的專用動畫。
- **護衛機器人**：原版是 `bigsize_chara`（64×64 一格），大地圖的頭目標記只能畫 32×32，所以用縮成一半的圖（`assets/bg/zgc_guard.png`，建資料時產生）；碰到就觸發（同 Z4 金屬古拉篇的機器人兵）。
- **海盜船動畫**：原版畫在大地圖上面，重製版的過場是黑底，所以船在黑底上橫越。
- **圖片放大**：原版用 200% 顯示的黑色底圖（萊奇登場 01、宇宙船 01）照原尺寸畫（反正是全黑）；哈奇亞克登場的灰色加算閃光用白色閃光代替（不透明度 127／188／255）。
- **大事な物**（紫晶石、星之貝殼、破魔的指環／珍珠、淚之書）重製版沒有這種物品，只照原版播「Ｚ戰士們得到了…」的文字；劇情進度照原版看開關。
- **遇敵頻率**用重製版共通的步數；地圖 105 的遇敵數（3～6）與地圖 110 開關 845 後的一組，由 `src/zg_c.js` 依狀態換上（`world.areas` 是固定資料）。
- **劇情戰前先存檔**；打輸讀檔回到那場戰鬥（原版是 Game Over）。海盜船動畫開始前也存檔，讀檔會從動畫接下去。
- 頁 6681 的分歧條件是「變數 320（回合數）≥ 0」，永遠成立，所以照原版一律接奧佐特戰。
- 原版的「概況」用 ZG 劇情場景（z1field 6771～6775）沒做（`docs/zg-plan.md` 沒有分到；目前 ZG 期間的概況照共通的處理）。
- 視窗外觀切換（`set_skn`）、倍速開關（CE173／174）、大猿解除（CE160）不需要。
